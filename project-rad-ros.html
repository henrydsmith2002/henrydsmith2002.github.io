ROS Mobile Robot Control & Coordination (RAD Lab)

Work centered on building and debugging ROS-based control software on physical robotic hardware. Emphasis was on closed-loop behavior, stability, and diagnosing integration issues observed during live testing.

What I built

  • ROS nodes in C++/Python for control, messaging, and system coordination
  • Closed-loop controller tuning to improve stability and repeatability
  • Integration fixes for sensor/actuator timing and runtime issues during testing

Engineering focus

  • Real-time debugging: observe behavior → isolate cause → implement fix → validate on hardware
  • Reliability: changes that make the system more predictable and repeatable
  • Clear documentation of issues and fixes to support team collaboration
