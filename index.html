About Me

I build robotics software that runs in real time on physical hardware. My interests center on ROS-based robotic systems, sensor integration, and closed-loop control, with a strong emphasis on writing reliable software that translates directly into stable and predictable robotic behavior.

Projects

ROS Mobile Robot Control & Coordination

Designed, implemented, and debugged ROS-based control software for mobile robotic systems operating on physical hardware. This work focused on coordinating sensors and actuators in a Linux environment, implementing closed-loop control, and resolving real-time integration and stability issues observed during live testing.

Light-Following Autonomous Robot

Developed embedded C++ control logic for a mobile robot capable of autonomously tracking and following a light source. Integrated sensors, motor drivers, and microcontroller I/O, and debugged real-time hardware–software interactions through iterative testing and calibration.

BYU Mars Rover Team

Member of the BYU Mars Rover Team, contributing to the development of robotics software using ROS2. This work emphasizes building reliable systems, understanding large robotics codebases, and learning best practices for simulation, testing, and hardware integration in a team-based environment.
