Hardware-in-the-loop autonomous raft simulation

Connecting a physical raft controller to ShipSim3 for closed-loop testing, with a hydrodynamic model identified from experimental data.

Problem / objective

Testing and tuning raft control algorithms required deploying a raft on water, taking substantial time and resources. The LIDSS group needed a way to test its physical control board in a simulated environment, with communication latency below 50 ms per message.

My contribution

I implemented the hardware-in-the-loop interface between the physical CORE control board and ShipSim3. I also configured the simulator’s hydrodynamics to reproduce raft behavior, using measured wet-test data to identify a damping model.

Technical approach

A closed loop through real hardware

A Python interface translates and routes navigation information from ShipSim3 to the CORE board, then returns the board’s motor commands to the simulation. GPS data reaches CORE over serial; other communication uses UDP.

I used socket and pyserial for communication, a state class for data handling, and threading so sending and receiving could happen simultaneously.

Identifying the raft’s hydrodynamics

  1. Collected inputs from provided wet-test GPS position, heading, and motor-command records.
  2. Smoothed the measured data with a Savitzky–Golay filter.
  3. Used a three-degree-of-freedom marine craft model to solve for residual damping forces in surge, sway, and yaw.
  4. Fit damping equations with linear least-squares regression and entered the resulting coefficients into ShipSim3.

Results

UDP forwarding completed in less than 1 ms per message. Serial latency had a 95th-percentile value of 21 ms , meeting the 50 ms (20 Hz) real-time requirement.

Yaw-rate normalized root mean square error (NRMSE) was 15% against wet-test data and 22% against independent mission data . Wet-test surge-velocity NRMSE was 23%; yaw-rate accuracy was prioritized.

The interface enabled closed-loop controller testing with the physical board, without deploying a raft for each test.
