Brigham Young University / ME EN 330

Line-following autonomous robot

An embedded-C mobile robot that follows a line and avoids obstacles using real-time sensor feedback.

  • Embedded C
  • Reflectance sensors
  • Distance sensors
  • Motor control

Objective

Program a mobile robot to follow a line while responding to obstacles in its path.

My contribution

I programmed embedded-C control logic to connect real-time sensor feedback to motor commands, using calibrated reflectance and distance sensors.

Technical approach

Reflectance sensors supplied line-position feedback, while distance sensors supplied obstacle feedback. The motor-control logic used these inputs to guide the mobile robot.

Outcome

The robot combined line following and obstacle avoidance through sensor feedback and embedded motor-control logic.
