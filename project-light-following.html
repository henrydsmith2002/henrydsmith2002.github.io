Light-Following Autonomous Robot (Embedded C++)

An embedded robotics project focused on control logic, sensor integration, and real-time debugging on a mobile platform.

What I built

  • Embedded C++ control loop to track a light source using sensor inputs
  • Motor driver and microcontroller I/O integration
  • Testing and calibration workflow to validate behavior and reduce instability

What I learned

  • How sensor noise and timing can destabilize behavior if not handled carefully
  • Debugging hardware–software interaction under real constraints
  • How small tuning changes can significantly improve performance
